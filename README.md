# VLM 02 — Vision Transformers: ViT, DeiT, Swin, DINOv2 & SAM

A deep-technical presentation covering the evolution of vision Transformer architectures: ViT patch embeddings, DeiT data-efficient training recipes, Swin hierarchical windowed attention, DINOv2 self-supervised dense features, SAM promptable segmentation, patch size and resolution trade-offs, and how each architecture plugs in as a VLM image encoder.
